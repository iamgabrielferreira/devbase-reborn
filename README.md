# DEVBASE — Java Edition

Projeto de desenvolvimento e aprendizado em Java, criado como uma nova versão do DevBase, originalmente desenvolvido durante minha formação acadêmica.

A proposta desta versão é reconstruir o projeto utilizando Java, aplicando na prática os conceitos estudados e evoluindo gradualmente a estrutura da aplicação.

**O principal objetivo é desenvolver minha capacidade de resolver problemas, estruturar soluções e escrever código de forma independente.**

> Este projeto é também um laboratório de evolução técnica. Cada funcionalidade representa um desafio de lógica, organização e aplicação dos conhecimentos adquiridos.

---

## Objetivos do projeto

- Desenvolver autonomia na resolução de problemas.
- Fortalecer a lógica de programação por meio de desafios práticos.
- Aplicar orientação a objetos e boas práticas de desenvolvimento.
- Trabalhar com persistência de dados e bancos relacionais.
- Evoluir gradualmente para uma aplicação backend utilizando Java e Spring Boot.

## Metodologia de desenvolvimento

Uma das principais propostas desta versão é desenvolver as funcionalidades sem utilizar IA para escrever ou solucionar os desafios de programação.

O processo de desenvolvimento prioriza:

- Implementação independente das funcionalidades.
- Consulta à documentação oficial quando necessário.
- Reaproveitamento de conhecimentos e experiências adquiridos em outros projetos.
- Testes manuais e validação das soluções desenvolvidas.
- Refatoração do código conforme a evolução do aprendizado.

O objetivo não é apenas fazer o código funcionar, mas entender as decisões tomadas durante sua construção.

## Sobre o projeto

O DevBase Java não tem como objetivo apresentar um código perfeito desde o início, mas documentar uma evolução real.

A ideia é enfrentar dificuldades, pesquisar, testar possibilidades, errar, corrigir e, principalmente, desenvolver a capacidade de transformar problemas em soluções através da programação.

**Menos dependência de respostas prontas. Mais prática, raciocínio e autonomia.**
