# 💻 DevBase — Edição Java

Nova versão do **DevBase**, projeto que desenvolvi originalmente durante minha formação acadêmica, agora reconstruído em **Java**.

A ideia é simples: aplicar na prática o que estou treinando e **evoluir a aplicação junto com meu aprendizado**, do básico até Spring Boot e API REST.

> Este repositório também é um laboratório da minha evolução como desenvolvedor. Cada funcionalidade é um desafio de lógica, organização e aplicação do conhecimento.

## 🧩 Metodologia

Uma das principais propostas desta versão é desenvolver as funcionalidades **sem usar IA para escrever o código ou resolver os desafios de programação**.

O processo prioriza:

1. Implementação independente das funcionalidades
2. Consulta à documentação oficial quando necessário
3. Reaproveitamento da experiência de outros projetos
4. Testes manuais e validação das soluções
5. Refatoração conforme o aprendizado evolui

O objetivo não é só fazer o código funcionar, mas **entender as decisões** tomadas durante a construção.
